# Code of Conduct

Kinboard adopts the [Contributor Covenant](https://www.contributor-covenant.org/) version 2.1 as its code of conduct. The full text is maintained at:

> https://www.contributor-covenant.org/version/2/1/code_of_conduct/

In short: be respectful, assume good faith, and help keep the project welcoming for contributors of every background and experience level.

## Reporting

If you observe behavior that violates the Contributor Covenant, please contact the maintainer at:

**conduct@kinboard.app**

Reports are confidential. The maintainer will acknowledge within 7 days and follow the enforcement guidelines linked in the Covenant document.

## Scope

This code applies to all project spaces — GitHub issues, pull requests, discussions, the project's social channels, and any in-person events held in the project's name.
