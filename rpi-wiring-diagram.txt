RASPBERRY PI 5 GPIO HEADER (40-pin)
===================================
Looking at Pi with USB ports facing down, GPIO header at top:

                    3V3  (1) (2)  5V  ←── RED wire to LD2410 VCC
                  GPIO2  (3) (4)  5V  ←── RED wire to RELAY VCC
                  GPIO3  (5) (6)  GND ←── BLACK wire to LD2410 GND
                  GPIO4  (7) (8)  GPIO14 (TXD) ←── ORANGE wire to LD2410 RX
                    GND  (9) (10) GPIO15 (RXD) ←── YELLOW wire to LD2410 TX
                 GPIO17 (11) (12) GPIO18
                 GPIO27 (13) (14) GND ←── BROWN wire to RELAY GND
                 GPIO22 (15) (16) GPIO23 ←── BLUE wire to RELAY IN
                    3V3 (17) (18) GPIO24
                 GPIO10 (19) (20) GND
                  GPIO9 (21) (22) GPIO25
                 GPIO11 (23) (24) GPIO8
                    GND (25) (26) GPIO7

                    GND (39) (40) GPIO21


LD2410 RADAR SENSOR WIRING
==========================

    LD2410 Module                    Raspberry Pi 5
    +------------+                   +------------------+
    |            |                   |                  |
    |  VCC ──────┼─── RED ──────────►│ Pin 2  (5V)      |
    |            |                   |                  |
    |  GND ──────┼─── BLACK ────────►│ Pin 6  (GND)    |
    |            |                   |                  |
    |  TX ───────┼─── YELLOW ───────►│ Pin 10 (RXD)    |  ← Pi RECEIVES here
    |            |                   |                  |
    |  RX ───────┼─── ORANGE ───────►│ Pin 8  (TXD)    |  ← Pi SENDS here
    |            |                   |                  |
    |  OUT ──────┼─── (not used)     |                  |
    |            |                   |                  |
    +------------+                   +------------------+

    IMPORTANT: TX/RX are CROSSED!
    - Sensor TX → Pi RX (Pin 10)
    - Sensor RX → Pi TX (Pin 8)


5V RELAY MODULE WIRING (for display power control)
==================================================

    Relay Module                     Raspberry Pi 5
    +------------+                   +------------------+
    |            |                   |                  |
    |  VCC ──────┼─── RED ──────────►│ Pin 4  (5V)      |
    |            |                   |                  |
    |  GND ──────┼─── BROWN ────────►│ Pin 14 (GND)    |
    |            |                   |                  |
    |  IN ───────┼─── BLUE ─────────►│ Pin 16 (GPIO23) |
    |            |                   |                  |
    +------------+                   +------------------+

    Relay OUTPUT connections (to monitor power):
    - COM (Common) → Monitor power input (+)
    - NO (Normally Open) → Power supply (+)
    - NC not used

    When GPIO23 = HIGH → Relay closes → Monitor ON
    When GPIO23 = LOW  → Relay opens  → Monitor OFF


COMPLETE WIRING SUMMARY

TESTING COMMANDS
================

# Test LD2410 sensor (after wiring):
sudo systemctl start presence-detector
sudo journalctl -u presence-detector -f

# Test MQTT presence messages:
mosquitto_sub -t "familyboard/presence" -v

# Test relay/display control:
mosquitto_pub -t "familyboard/display/power" -m "off"
mosquitto_pub -t "familyboard/display/power" -m "on"
mosquitto_pub -t "familyboard/display/power" -m "toggle"

# Check display status:
mosquitto_sub -t "familyboard/display/status" -v


SERIAL PORT INFO
================
Device: /dev/serial0 → /dev/ttyAMA10
Baud rate: 256000 (LD2410 default)
If sensor doesn't respond, try 9600 baud (older firmware)


MQTT TOPICS
===========
familyboard/presence        - Presence state {"presence": true/false, "state": "on"/"off"}
familyboard/display/power   - Send: on/off/toggle
familyboard/display/status  - Current display state (on/off)
familyboard/system/command  - Send: reboot/refresh/screenshot
familyboard/system/status   - System status (online/offline/rebooting)
